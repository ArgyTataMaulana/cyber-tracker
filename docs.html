📄 Project Documentation v2.0

StudyHub — Academic Tracker for Gen Z

Aplikasi web personal untuk mahasiswa dengan gamification, dual mode (Liburan & Semester), dan fitur yang bikin Gen Z ketagihan belajar.

📦 6 Files
🛠️ HTML + CSS + JS
💾 localStorage
🎨 Dark Theme

🏗️ Arsitektur Sistem

Single Page App (SPA) dengan hash-based routing, tanpa framework, tanpa backend.

🔥 Streak & Daily Challenge

🔥 Streak

  • +1 setiap hari aktif (min 1 task atau 15 min timer)
  • Streak Freeze: 1x per minggu, skip tanpa putus
  • Milestones: 7, 14, 30, 60, 100 hari → bonus XP + badge
  • Visual fire animation — makin besar seiring streak

📋 Daily Challenge

  • "Selesaikan 3 task hari ini" → +25 XP
  • "Belajar 1 jam tanpa jeda" → +30 XP
  • "Buat 2 catatan baru" → +15 XP
  • Berubah tiap hari, seeded by date

✅ Verification Plan

Checklist pengujian sebelum siap dipakai.

  • ☐ CRUD Matkul — Tambah, edit, hapus → data persist setelah refresh
  • ☐ CRUD Jadwal — Buat jadwal → tampil di weekly view → highlight hari ini
  • ☐ CRUD Tugas — Tambah → deadline badge benar → kanban drag works
  • ☐ Nilai & IPK — Input → auto-hitung → simulator akurat
  • ☐ Timer — Stopwatch & Pomodoro → log tersimpan → XP diberikan
  • ☐ Gamification — XP ↑ → level up → badge unlock → animation
  • ☐ Streak — Login tiap hari → naik → freeze works
  • ☐ Share Card — Generate → download PNG → terlihat bagus
  • ☐ Heatmap — Data muncul → warna benar → hover tooltip
  • ☐ Responsive — Desktop sidebar ↔ mobile bottom bar
  • ☐ Theme — Dark/Light switch → accent color → persist
  • ☐ Export/Import — Export JSON → import → semua kembali
  • ☐ Keyboard Shortcuts — Semua shortcut berfungsi
  • ☐ Focus Mode — Fullscreen → ambient → Escape keluar
